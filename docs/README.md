# docs/

Supporting material for the Random Quote Generator submission.

```
docs/
  README.md                 # this file
  design-notes.md           # longer-form design inspiration notes
  screenshots/              # UI screenshots referenced from the root README
    README.md               # capture instructions and file naming
```

## Contents

| File | Purpose |
| --- | --- |
| [`design-notes.md`](./design-notes.md) | Why the app looks and behaves the way it does: typography, palette, motion, theme, layout. |
| [`screenshots/`](./screenshots/) | Drop captured screenshots here; the root README links to them. See the capture checklist inside. |

## Conventions

- Screenshot files use lowercase kebab-case, e.g. `320px-light.png`.
- Preferred format is PNG at the device's native pixel density (see
  `screenshots/README.md` for exact sizes).
- Keep design notes in Markdown so they stay reviewable in a pull request.
